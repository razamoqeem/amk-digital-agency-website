    Tester allowances (Owner & team)

    Individual tool daily caps

    Optional daily caps on heavier tools to protect server resources. Set to 0 to use the standard daily visitor limit.

    How changes take effect

    • Clicking Save limits updates content/limits.json immediately.

    • The website tool service reads this file on every request, so changes work instantly without restarting.

    • To clear test counters on your local machine, run python -m api.reset_usage in terminal.
