Meta descriptions: what they do and how to write them

The meta description can become the short text under your result. Learn when Google uses it and how to write one that helps people decide to click.

By AMK Digital Agency · Published 18 November 2026 · 2 min read · 387 words

On this page
  1. How Google chooses the snippet
  2. Length
  3. How to write a good meta description
  4. Common mistakes

A meta description is a short summary inside the page's code: <meta name="description" content="…">. Visitors do not see it on the page itself, but search engines can show it as the snippet under your result.

How Google chooses the snippet

Google creates snippets automatically. The page's own content is the main source. Google may use the meta description instead when it gives a better summary of the page than the text on the page does.

Where the snippet comes from
SituationLikely snippet source
The meta description accurately summarises the pageOften the meta description
The meta description is missingText taken from the page
The meta description is vague or repeated on many pagesText taken from the page
The search is about one specific detail on the pageThe part of the page that matches the search

Length

There is no limit on how long a meta description can be. In results, snippets are shortened as needed, usually to fit the device width. Keep the most useful information at the start so it is still visible after shortening.

How to write a good meta description

  1. Summarise the page honestly

    Say what the visitor will find: the topic, the format and who it is for.

  2. Include useful specifics

    Facts such as a price range, opening hours, a product's key feature or the steps covered.

  3. Make it unique

    Avoid one generic description copied across many pages. If you have many pages, start with the most important ones.

  4. Read it as a searcher

    Would this sentence help you choose between results?

Tip

If a site has thousands of similar pages, such as product pages, descriptions can often be generated from each page's own data (name, key details, price) so every one is different and accurate.

Common mistakes

  • The same description on many pages
  • A list of keywords instead of a sentence
  • A description that does not match the page
  • No description on the most important pages

Check any page with our free Meta Tag Analyser: it shows the description, its length and a search result preview.

Will Google always show my meta description?

No. Google chooses the snippet for each search and may use text from the page instead, especially when the search is about a specific detail.

References

  1. Control your snippets in search results — Google Search Central

Key takeaways

  • Google mainly builds snippets from the page content, and uses your meta description when it describes the page better.
  • There is no length limit; long descriptions are shortened to fit the screen.
  • Write a unique description for each important page, starting with your key pages.
