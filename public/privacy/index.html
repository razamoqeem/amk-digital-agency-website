Legal bases (where the GDPR or UK GDPR applies)

  • Legitimate interests: running the free tools, counting free runs and protecting the service from abuse.
  • Consent: answering a request you send with the form (you tick a box to agree). You can withdraw consent at any time.
  • Strictly necessary storage: the visitor cookie is needed for the free-run limits you ask to use.

Service providers

These companies process information on our behalf to run the website:

  • Vercel: hosting. Servers that run the tools are in the United States (Washington, D.C. region). Vercel keeps technical logs, which can include IP addresses, under its own policies.
  • Upstash: database for usage counters and, if no other destination is set, request form submissions. Region: United States (east).
  • Cloudflare Turnstile: a security check that tells people from automated traffic. Cloudflare processes information such as your IP address and browser signals for this purpose.
  • Public sources a tool reads: the website you ask a tool to check, the domain registries (RDAP or WHOIS) and DNS. These receive only what is needed for the check.

The website has an AI chat assistant that is currently switched off. If it is switched on, messages you type would be sent to an AI provider (Google or OpenRouter) to produce a reply; this policy will be updated before that happens.
