# SEO Starter Guide: Foundational Best Practices

## 1. Help Google Find Your Content
- **`site:` operator**: Use to check indexing status.
- **Sitemaps**: Help Google discover important URLs and metadata (update frequency).
- **Crawlable Links**: Use `<a>` tags with `href` attributes. Google cannot follow `onclick` or `button` navigation.

## 2. Organization & Structure
- **Descriptive URLs**: Use breadcrumb-like structures (e.g., `/pets/cats.html` vs `/id/67727`).
- **Topical Grouping**: Group similar pages in directories to help Google learn crawl frequency patterns.
- **Canonicalization**: Use `rel="canonical"` to specify the preferred version of duplicate content.

## 3. Content Optimization
- **Helpful & Reliable**: Focus on unique, easy-to-read, and expert-level content (E-E-A-T).
- **Link Text (Anchor Text)**: Use descriptive text that explains the destination (avoid "click here").
- **Images**:
  - High-quality images near relevant text.
  - Descriptive `alt` text for accessibility and search context.
- **Videos**: Standalone pages with descriptive titles/descriptions and high-quality embedding.

## 4. Search Appearance
- **Title Links**: Unique, clear, and concise titles (using `<title>` and `<h1>`).
- **Snippets**: Controlled via Meta Descriptions or sourced from high-quality page content.

## 5. Technical Essentials
- **HTTPS**: Secure connections are a ranking factor and user trust signal.
- **Mobile-Friendliness**: Google uses mobile-first indexing; ensure responsive design.
- **Page Experience**: Fast loading (Core Web Vitals) and avoiding intrusive interstitials.
