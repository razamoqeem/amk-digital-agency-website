## 📄 1. ON-PAGE HYPER-OPTIMIZATION
Every post and page must satisfy these "God-Mode" attributes. Failure results in a critical "System Red Flag."

1.  **Slug Integrity (Sentiment Optimized)**:
    *   Must be lowercase, hyphenated, and trigger a high **Click-Probability Score**.
    *   **Sentiment Match**: Slugs must align with the user's emotional search intent.
2.  **Heading Hierarchy (Intent-Based)**:
    *   Exactly one `H1` per page.
    *   Every `H2` must solve a unique **User Intent** stage (e.g., Awareness, Comparison, Conversion).
3.  **Meta Intelligence (Dynamic A/B Testing)**:
    *   **Meta Title**: 50-60 characters. Must be drafted in 3 variations for API-driven A/B testing.
    *   **CTR Threshold**: If a page's CTR drops below **3%**, the Auditor automatically triggers a title refresh.
4.  **Visual Assets (AI-Compressed)**:
    *   **The 50KB Rule**: No image should exceed **50KB**. Use AI-driven compression to reach the absolute visual threshold (40-60KB).
    *   **Alt Text**: Required for every image (Accessibility & SEO).

## ⚙️ 2. PERFORMANCE & INFRASTRUCTURE (EXTREME)
Focus on "First Packet" visibility and indexation aggression.

1.  **Zero-JS Execution (The 14KB Rule)**:
    *   All critical SEO content must be 100% visible in the first **14KB** of the HTML packet.
    *   Minimize dependencies to ensure instant AI-crawler readability.
2.  **Indexation Aggression**:
    *   **60-Second Rule**: Every new or updated page must be pinged to Google Indexing API and Bing Webmaster API within 60 seconds of publication.
3.  **Code Health**:
    *   **File Bloat**: Zero tolerance for unused CSS/JS. Total page weight must be under 200KB for maximum mobile dominance.

## 🔗 3. THE AUTHORITY MOAT & LINK INTELLIGENCE

4.  **Provenance Scoring**: Strictly monitor the "Trust Graph" of all incoming links.
